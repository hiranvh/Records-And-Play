# GitHub Project Description

## Short Description (for repo header)

Drift-aware Python Playwright QA replay platform with Record/Replay, self-healing selectors, replay modes, and Excel/JSON evidence reports.

## Extended Description (for README or About section)

This project is a production-focused QA replay platform built with FastAPI and Playwright. It records browser workflows, replays them with validation intelligence, and surfaces drift indicators such as missing/new fields, healed selectors, and warnings. Teams can run in Lenient, Standard, or Strict mode and export Excel + JSON artifacts for both stakeholder review and analytics tooling.
