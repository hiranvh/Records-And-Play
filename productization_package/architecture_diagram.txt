Operational Data Flow

1) Record workflow -> save JSON
2) Replay workflow in selected mode
3) Collect discrepancies and recovery stats
4) Generate Excel + JSON artifacts
5) Surface analytics cards + run history + report downloads in UI
6) Track trend-ready metrics across runs
