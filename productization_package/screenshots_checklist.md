# Screenshots Checklist

Use this checklist to build a polished README, demo deck, and launch post.

## Capture Settings (Recommended)

- Resolution: 1920x1080
- Browser zoom: 100%
- Hide sensitive data and credentials
- Use consistent window size across all shots
- Include timestamped run data when possible

## Required Screenshots

1. Landing Console
- Screen: Main app (`/record-and-play`)
- Show: URL input, workflow selector, mode tabs
- Filename: `01_main_console.png`

2. Record Mode
- Screen: Record tab before run
- Show: Start Recording controls
- Filename: `02_record_mode.png`

3. Replay Mode Controls
- Screen: Replay tab controls
- Show: Lenient/Standard/Strict dropdown + policy toggles
- Filename: `03_replay_mode_controls.png`

4. Replay Analytics Cards
- Screen: Replay analytics section
- Show: Missing fields, New fields, Healed selectors, Warnings, Run mode
- Filename: `04_replay_analytics_cards.png`

5. Run History Table
- Screen: Replay run history table
- Show: recent runs with status/mode/duration
- Filename: `05_run_history_table.png`

6. Report Download Actions
- Screen: Replay report area
- Show: Download Excel and Download JSON buttons
- Filename: `06_report_download_actions.png`

7. Dashboard Overview
- Screen: Dashboard page (`/record-and-play/dashboard`)
- Show: KPI cards and run summary
- Filename: `07_dashboard_overview.png`

8. Dashboard Reports Panel
- Screen: Dashboard report cards/list
- Show: report catalog and links
- Filename: `08_dashboard_reports.png`

9. Live Logs Monitor
- Screen: Logs page (`/record-and-play/logs`)
- Show: streaming logs, filters, connection status
- Filename: `09_live_logs.png`

10. Excel Report Artifact
- Screen: opened `.xlsx` report
- Show: discrepancy summary and key columns
- Filename: `10_excel_report.png`

11. JSON Report Artifact
- Screen: JSON report excerpt
- Show: `qa_summary`, `run_metrics`, `trend_ready`
- Filename: `11_json_report.png`

12. End-to-End Evidence Collage (Optional)
- Screen: single slide collage
- Show: controls + analytics + reports + logs
- Filename: `12_collage.png`

## Quality Checklist Before Publishing

- No PII or secrets visible
- Text is legible at normal zoom
- Same theme and layout style across images
- At least one screenshot includes trend/analytics evidence
- Filenames are ordered for storytelling
